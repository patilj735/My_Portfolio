# Developer Portfolio

A personal developer portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

The portfolio is designed to showcase my projects, technical skills, experience, certifications, and ways to get in touch with me. I focused on keeping the interface clean and modern while adding subtle animations and interactions throughout the site.

## Tech Stack

* React
* Vite
* Tailwind CSS
* Framer Motion
* Lucide React
* JavaScript

## Features

* Responsive design for desktop, tablet, and mobile
* Animated hero section and page sections
* Smooth scroll navigation
* Interactive project cards
* Project details modal
* Project filtering
* Skills and technology section
* Experience timeline
* Certifications section
* Contact section
* Keyboard-friendly navigation
* Reduced-motion support
* SEO and social sharing meta tags
* Custom cursor and interactive UI effects

## Projects

The portfolio includes some of my development projects across different areas, including:

* Full-stack MERN applications
* React applications
* AWS and serverless projects
* JavaScript projects
* Cloud-based applications

Each project includes its technology stack, description, and relevant links where available.

## Run Locally

Clone the repository:

```bash
git clone <your-repository-url>
```

Go to the project directory:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```

## Build for Production

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Deployment

The project can be deployed using platforms such as Vercel.

For a Vite project, the production build is generated in:

```text
dist/
```

Typical build settings:

```text
Build Command: npm run build
Output Directory: dist
```
